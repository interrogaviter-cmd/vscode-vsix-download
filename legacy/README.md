# 历史归档

这里保留合并前的原始文件，供比较和追溯插件名单。维护入口为项目根目录的 `download_vscode_extensions.py`。

- `download.py`、`download_new.py`、`download_new_single.py`：已合并的历史下载器。
- `download_vscode_extensions_before_merge.py`：合并前主版本备份。
- `install_windows.bat`、`install_linux.sh`：旧安装脚本，目录配置已过时；Windows 文件内容实际为 PowerShell。

历史 VSIX 包仍在原来的仓库目录中。部分包内平台与文件名不一致，详见根目录 README。
